# TaxEaseBD backend dependencies.
#
# Kept deliberately small: no torch/transformers/langchain/faiss.
# Those belonged to an abandoned RAG experiment (backend/main.py used to be
# that script) that was never wired into the actual API and pulled in
# ~1.5GB of ML dependencies that frequently fail to install on Windows
# without build tools.
#
# `groq` below is the one exception: it's a lightweight, pure-Python HTTP
# client (no ML weights, no heavy deps) used to generate plain-language
# answers grounded in whatever main.py's retrieval logic already found in
# income_tax_laws - see llm.py. It's optional at runtime: without a
# GROQ_API_KEY in .env, /api/chat still works, just with a templated
# answer instead of an LLM-phrased one.
